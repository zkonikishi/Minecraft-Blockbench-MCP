# 后续开发计划

## YSM／时装工坊模型离线恢复

登记日期：2026-09-09。

**状态：已列入未来计划；未实现、未验证。延后执行，不改变 CraftEngine Alpha 8 的交付优先级。**

目标：将 Yes Steve Model（YSM）及 Armourer's Workshop（时装工坊，AM/AW）模型文件离线转换为 `.bbmodel`，恢复能够可靠解释的几何、骨骼、贴图与动画，并提供逐项恢复报告。不承诺重建原始工程或无损恢复。

### 拟定结构

- 独立转换核心：`src/converters/ysm/`、`src/converters/armourers-workshop/`，处理输入字节及格式数据，不依赖游戏或编辑器全局对象。
- 独立离线 CLI：拟设 `scripts/convert-model.mjs`。纯转换无需启动 Minecraft、Mod 或 Blockbench。
- MCP 薄封装：提供格式识别、转换和恢复报告；具体工具名、参数在样本验证后确定。
- 可选编辑器导入：复用 `mc_import_bbmodel`，在已连接的 Blockbench 中新建标签并保留旧工程。只有此步骤需要运行 Blockbench。

### 开发前置条件与待办

- [ ] 收集各目标格式及版本的可授权使用样本，记录精确 Mod 版本和加载器。
- [ ] 每个版本至少准备最小模型，另准备含骨骼、动画及贴图的样本；尽可能提供对应原始 `.bbmodel` 用于比对。
- [ ] 核实 YSM 旧格式与新格式差异、压缩／加密容器及解码所需的官方接口或材料，不预先假定格式兼容。
- [ ] 核实时装工坊的格式与版本差异，评估其许可和本项目代码复用边界；不直接搬运带 NC 限制的代码。
- [ ] 分别验证几何、层级、变换、UV、贴图、关键帧与动画语义的恢复范围。
- [ ] 为每个已验证版本建立兼容性与数据损失清单，区分完整恢复、近似转换、遗漏和不支持。
- [ ] 以原始工程或已知预期验证转换结果；无法恢复的内容必须在报告中显式说明。

以上目录、CLI 和接口均为规划，不代表当前发布版本已有相应能力。
